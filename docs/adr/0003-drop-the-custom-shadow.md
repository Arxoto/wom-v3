# 去掉自绘阴影，阴影一律用系统原生阴影

自绘阴影那条路（`custom_shadow` + `index_frame.html`）只在没有 Window Effect 时才可能出现，而它要求窗口比内容大 48px、面板四边留白、自绘圆角与阴影，尺寸完全靠 CSS 与 `layout_coupling` 手工对齐；一旦窗口透明并叠上原生材质，那圈留白又会露出材质，看着就是脏的双层效果。所以删掉整条路径：窗口阴影一律交给系统原生阴影，不启用原生效果的外观拆成 `Solid`（无原生框架）与 `Framed`（带原生框架）两种，窗口尺寸也只需要再为 1px 发丝线留出 2px。代价是阴影的形状、颜色、扩散不能再由 WOM 定制，旧配置里的 `custom_shadow` 键会被忽略（ADR-0002 随之作废）。
