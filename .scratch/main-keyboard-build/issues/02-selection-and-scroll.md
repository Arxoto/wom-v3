# 02: ↑/↓ 选中与滚动

**What to build:** 上下键移动 `Selection`，高亮跟着走；结果超过可见行数时列表整体滚动，高亮停在倒数第二行。

**Blocked by:** 01

**Status:** resolved

- [x] 按键只有一个入口：`window` 捕获阶段的 `keydown`；入口不挂在真实输入框上（预览打开、鼠标点过 body 之后按键仍要生效）
- [x] `↑` / `↓` 移动 `Selection`，边界 clamp 不环绕；按住连发限流 100ms，首次按键立即响应
- [x] 未识别的键与 `←` / `→` 放行：不产生意图、不阻止默认行为
- [x] 新结果回来 `Selection` 回到第一条
- [x] 高亮走到倒数第二行时列表整体上移一行、高亮停在同一屏幕行；下面没有更多结果时才继续下移；`↑` 对称
- [x] 选中行有可见样式，与鼠标悬停不是同一套语义
- [x] 结果为空时，依赖条目的意图一律退化成无操作

依据：[spec.md](../main-keyboard/spec.md) §1 的按键表、§2 的 `MainState`、§5 的滚动模型。
