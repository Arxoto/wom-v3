# 04: 显示时聚焦并全选

**What to build:** 主窗口每次显示，先强制关掉 `Preview`，再让输入框聚焦并全选内容；启动即显示也成立。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 显示分支（显示窗口的那几处）向主窗口发一条无载荷事件
- [ ] 前端监听该事件：关掉 `Preview` + 聚焦并全选输入框
- [ ] 前端挂载时也做一次，覆盖「启动即显示」时事件早于前端就绪的情况
- [ ] 隐藏再唤出后，输入内容与已加载的结果都保留
- [ ] 唤出等于重新开始：上一次留在屏上的 `Preview` 不会跟着回来

依据：[spec.md](../main-keyboard/spec.md) §3 的「显示 / 退场」、§4.5。
