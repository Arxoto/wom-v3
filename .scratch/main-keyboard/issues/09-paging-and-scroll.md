# 分页与滚动

Type: grilling
Status: resolved

## Question

结果超过一页时怎么办？列表滚动的模型是什么？

## Answer

- Rust 一次返回一页（现在是 `search::PAGE_SIZE`）；前端把新页**追加到已加载列表末尾**，不换页、不重置。
- **预请求余量写死 10**（不跟随 `main_item_n`）：选中索引 = 已加载条数 - 10 时发起下一页请求。
- 预请求要有 in-flight 表（同一页不重复请求）、失败后允许下次再试、新检索到来时整体作废（沿用同一套令牌规则）。
- **滚动模型**：可见行数 = `main_item_n`；高亮走到**倒数第二行**时再按 ↓，整个列表上移一行、高亮停在同一屏幕行，于是下面始终留一行可看；只有下面确实没有更多结果时，高亮才继续下移到可见区最后一行。↑ 对称（走到第二行时整体下移一行）。
- 本 effort 只做最简单的滚动，不含过渡动画；滚动位置由 `Selection` 现算，不占状态（见 [按键层与状态归属](04-key-layering-and-state-ownership.md)）。
