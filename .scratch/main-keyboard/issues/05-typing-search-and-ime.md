# 打字到检索的时序

Type: grilling
Status: resolved

## Question

打字怎么变成检索？合成期间哪些键放行？怎么防止响应乱序？按住方向键的连发怎么办？

## Answer

- **合成期间**：所有被拦截的键一律放行、不产生任何意图，交给输入法选候选 / 提交 / 取消。按 ESC 取消候选却把窗口关了、按 Enter 提交候选却触发了动作，都是硬伤。可靠判据以 [IME 合成期间的事件语义](01-research-ime-composition.md) 的结论为准。
- **检索时机**：非合成变更后 50ms 尾触发防抖；文本与上次发送相同就不重发（后端另有 `input_key` 缓存兜底）。
- **乱序**：请求令牌只与「当前最新令牌」比相等，**不比较大小**；令牌用有界环计数器（如 `% 256`，远大于同时在飞的请求数），数字不会无限增长，回绕也不会误判。
- **连发**：按住 ↑/↓ 限流约 100ms（写成常量）；触控板的惯性滚动不在此列。
